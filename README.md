# CharPrompt AI 🎨

A lightweight, professional front-end web utility designed to solve the biggest challenge in AI video generation and creative directing: **Character Consistency**. 

By framing AI prompts within a precise engineering template, this tool allows creators to lock in core character visual directives while dynamically changing scenes and actions.

## 🚀 Use Case Highlight
Perfect for creative directors building a consistent character-driven animated series. For example, maintaining strict visual continuity for an episodic 3D animation series like *Karaza's Daily Life*. The tool ensures the character's core visual directives remain immutable across sequential episodes and social media assets.

## ✨ Features
* **Strict Visual Continuity:** Generates heavily weighted prompts to force AI models (Midjourney, DALL-E) to maintain exact facial features and outfits.
* **Bilingual Support (UI):** Seamlessly switch between Arabic (RTL) and English (LTR) interfaces.
* **Modern Dark/Light Mode:** Built-in theme toggling with smooth CSS transitions and state memory.
* **Interactive UI/UX:** Features a live typing-effect animation for prompt generation.
* **Fully Responsive:** Optimized for both desktop and mobile workflows.
